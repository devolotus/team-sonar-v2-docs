# Documentação técnica

Documentação gerada pelo Devolotus a partir do commit registrado em `generation.json`.
As páginas ficam em `docs/`. Revise as inferências antes de usá-las em decisões operacionais.

Use Node 22, `npm ci` e `npm start` para leitura local. `npm run build` valida o site.
Push em `main` publica o site pelo workflow `deploy-pages.yml`. Publicar não consulta a IA.

A visibilidade do repositório e a do GitHub Pages são independentes. Consulte a configuração Pages.
